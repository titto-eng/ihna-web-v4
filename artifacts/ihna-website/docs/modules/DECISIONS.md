# Decisions (ihna-web)

The standing decisions. Code comments cite them by number (`DEC-n`); a number never changes meaning. Where a module doc and this
file disagree, fix the doc. Each row: decision as it stands on IHNA | why.

Numbers DEC-1 to DEC-99 are shared with ihm-web and mean the same thing in both repos, because the shared files
(`SHARED-FILES.md`) carry the same comments. Where IHNA applies a shared decision differently, the row says how; where a shared
decision has nothing to act on here, the row says so. Decisions that exist only for IHNA are numbered from DEC-101.
